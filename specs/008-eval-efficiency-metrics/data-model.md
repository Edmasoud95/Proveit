# Data Model: Eval Efficiency Metrics

## Modified Model: `EvalResult`

Add token usage fields (nullable — existing rows have no data):

| New Field | Type | Description |
|-----------|------|-------------|
| `promptTokens` | `Int?` | Total prompt tokens consumed by the agent across all loop iterations for this case |
| `completionTokens` | `Int?` | Total completion tokens generated by the agent across all loop iterations |
| `totalTokens` | `Int?` | `promptTokens + completionTokens` (mirrors OpenAI `usage.total_tokens`) |

**No changes** to `EvalRun` schema — aggregates are computed on-demand.

## No New Models

All aggregate metrics (accuracy, avgLatencyMs, avgPromptTokens, avgCompletionTokens, avgTotalTokens, efficiencyScore) are computed at query time from `EvalResult` rows. They are not persisted.

## Migration Strategy

SQLite `ALTER TABLE EvalResult ADD COLUMN` — straightforward nullable column addition, no table recreation needed.

```sql
ALTER TABLE "EvalResult" ADD COLUMN "promptTokens" INTEGER;
ALTER TABLE "EvalResult" ADD COLUMN "completionTokens" INTEGER;
ALTER TABLE "EvalResult" ADD COLUMN "totalTokens" INTEGER;
```

All new columns are nullable — zero data migration for existing rows. Legacy runs display `—` in token fields.

## Computed Shape: `RunMetrics`

Used in API responses — not a DB model:

```
RunMetrics {
  accuracy: number           // passedCases / totalCases, or null if totalCases=0
  avgLatencyMs: number|null  // mean of non-null EvalResult.latencyMs for this run
  avgPromptTokens: number|null
  avgCompletionTokens: number|null
  avgTotalTokens: number|null
  efficiencyScore: number|null  // accuracy / (avgLatencyMs / 1000), or null if avgLatencyMs=0/null
}
```
