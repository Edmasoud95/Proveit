# ProveIt

A sandbox platform for scaffolding, editing, and evaluating agent workflow POCs against local and external LLMs.

**Core loop**: describe a workflow → scaffold a POC config → connect an LLM → run LLM-as-judge evals.

---

## What it does

ProveIt lets developers go from idea to a running eval suite in minutes, without writing boilerplate. You describe an agent workflow in plain text; the platform generates a complete POC configuration — system prompt, tool definitions with mock responses, and eval cases — that you can immediately edit, run, and iterate on.

### Key capabilities

- **POC scaffolding** — describe a workflow, get a complete POC config (system prompt, tools, eval cases) generated by an LLM
- **Tool stubs** — define mock responses per tool so eval runs can complete the agent's reasoning loop without real integrations; generate stubs via LLM or write them manually
- **LLM-as-judge evals** — run eval cases against any connected LLM and receive per-case pass/fail verdicts with judge reasoning; no hardcoded expected outputs
- **Live streaming results** — eval progress streams case-by-case via SSE; results appear in real-time
- **Pipeline traces** — drill into any eval case to see the full execution trace: input, system prompt, every tool call (name + arguments + mock response), final LLM output, and judge verdict
- **Versioned eval suites** — any change to the eval case list creates a new suite version automatically; runs are tagged to their version so comparisons are always apples-to-apples
- **Multi-provider LLM routing** — connect multiple LLM providers per POC; route specific tasks (agent, judge, eval generation, stub generation) to different models independently
- **Export / import** — export any POC config as portable JSON; import eval cases from JSON files

## Getting started

### Prerequisites

- Node.js 20+ (see `.nvmrc`)
- pnpm 11 (`corepack enable` picks up the pinned version)
- A running LLM endpoint (defaults to [LM Studio](https://lmstudio.ai) at `http://localhost:1234/v1`; any OpenAI-compatible API works)

### Install and run

```bash
# Install dependencies
pnpm install

# Set up the database (first time only)
pnpm --filter backend db:setup

# Start the dev server (backend :3000 + frontend :5173)
pnpm dev
```

Open `http://localhost:5173`. Interactive API docs are served at `http://localhost:3000/api/docs`.

> **Security note:** Proveit is a local, single-user tool — there is no
> authentication and LLM API keys are stored in plaintext in the local SQLite
> database. Do not expose it beyond your machine. See [SECURITY.md](./SECURITY.md)
> for the full threat model.

### First POC in 5 minutes

1. Click **New POC** and describe your agent workflow in plain text
2. Review and edit the generated system prompt, tools, and eval cases in the POC editor
3. Go to **LLM Settings** and enter your endpoint URL (e.g. `http://localhost:1234/v1` for LM Studio)
4. Click **Test connection** — the platform fetches available models and confirms the connection
5. Go to **Eval Results** and click **Run Evals** — results stream in live

## Architecture

Monorepo with three packages:

| Package | Stack | Port |
|---------|-------|------|
| `packages/backend` | NestJS 10, Prisma 5 (SQLite), OpenAI SDK, RxJS | 3000 |
| `packages/frontend` | React 18, React Router 6, TanStack Query 5, Tailwind CSS 3, Vite 6 | 5173 |
| `packages/shared` | TypeScript interfaces only | — |

The frontend proxies all `/api` requests to the backend. The frontend never calls LLMs directly.

### Backend modules

| Module | Responsibility |
|--------|----------------|
| `poc/` | POC config CRUD; scaffold endpoint |
| `scaffold/` | Calls LLM with scaffold prompt, persists POC config and eval cases |
| `llm/` | LLM connection CRUD, health check, model listing |
| `eval/` | Eval case CRUD, AI generation, run execution, SSE streaming, metrics, LLM-as-judge scoring |
| `chat/` | Interactive chat with a POC's agent (streaming, session-only history) |
| `prisma/` | Global PrismaService |

### Frontend pages

| Page | Route | Purpose |
|------|-------|---------|
| `Home` | `/` | POC list + create form |
| `PocEditor` | `/poc/:id` | Tabbed editor: system prompt / tools / eval cases |
| `LlmConnect` | `/poc/:id/llm` | Provider list, connection test, model selector, advanced routing |
| `EvalResults` | `/poc/:id/evals` | Run evals, live stream, run history grouped by version, trace viewer |
| `Chat` | `/poc/:id/chat` | Chat with the POC's agent using its system prompt and tool stubs |
| `GlobalSettings` | `/settings` | Global (cross-POC) LLM providers |

## Design principles

- **Local-first** — works with no external dependencies; default endpoint is LM Studio at `localhost:1234/v1`
- **AI-assisted, not AI-replaced** — all generated config is visible and editable; the AI is a starting point
- **Frontend never calls LLMs** — all LLM communication goes through the backend
- **Progressive disclosure** — simple defaults with advanced options behind toggles
- **Minimal dependencies** — no component libraries; hand-crafted Tailwind components
- **No auth** — single-user, local tool; no login required (see [SECURITY.md](./SECURITY.md))
